真随机算法

数据库级两段式取图（COUNT + 随机 OFFSET），每次请求独立随机，无缓存无重复规律。

多级分类

无限层级分类树，API 指定分类即返回该分类及其子分类下的随机图片。

双模式返回

JSON 结构化数据或 302 重定向直接出图，同一个端点两种用法。

多存储实例

本地存储与六家对象存储（COS / OSS / S3 / OBS / 又拍云 / 七牛）官方 SDK 接入，签名直链与 CDN 加速。

速率限制

令牌桶算法限流，分级配额，响应头实时返回剩余请求数。

轻量核心

零重型框架的 PHP 8.4 自研核心，API 平均响应时间低于 50ms。
