## v1.2.0-beta.3

**版本概述**：安全与体验升级——图片链接全面改为短时临时签名链接（可配置有效期），图片管理分页增强、跨页全选，并修复批量上传、进度条与全选等三项问题。

### 🔒 安全增强（Security）

- **图片链接改为短时临时签名链接**（每个存储实例可配置有效期，默认 300 秒）：
  - 对象存储全部使用云商原生预签名，**不经服务器代理**（COS/OSS/AWS/OBS 预签名 URL、又拍云 `_up_t` token 签名、七牛 `?e&token` 下载签名）
  - 本地存储：新增签名下载端点 `/files`（HMAC-SHA256 校验 + 过期时间 + 路径穿越防护），永久静态 URL 改为短时签名链接
  - 配置了 CDN 加速域名的实例保留固定链接（公开加速场景）

### ⬆️ 功能增强（Enhancements）

- **图片管理分页**：新增每页数量选择（10/20/50/100），切换保留搜索/分类筛选条件
- **图片管理跨页全选**：「全选」按当前筛选条件选择全部图片（跨分页）；「全选本页」保留页级范围；选中集合跨页/跨筛选保留
- **存储管理**：本地存储实例支持配置「签名链接有效期（秒）」

### 🐛 Bug 修复（Bug Fixes）

- **图片上传**：进度条重做——百分比/「正在保存…」文字独立成行 + 胶囊渐变轨道，不再被裁剪、不再遮挡上传框
- **图片上传**：批量上传（如 24 张）超 post_max_size 时误报 419 CSRF → 改为明确 413 提示 + 前端上传前预检大小
- **图片管理**：修复「全选」接口 HTTP 500（对 Model 对象做数组访问）——改为轻量 SELECT id

### 升级指南（Upgrade Guide）

1. 下载下方 zip 资产覆盖部署（参考 README 快速开始）。
2. 重启 PHP-FPM 触发数据库自动迁移。
3. 运行 doctor.php 验证部署健康后删除。
4. 存储管理检查各实例「签名链接有效期」是否符合预期（默认 300 秒）。
