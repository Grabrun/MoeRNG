## v1.2.0

**版本概述**：MoeRNG 1.2.0 是 1.1.x 线以来的首个正式版本，围绕**安全、存储灵活性与运营体验**三个方向重构：图片链接全面改为短时临时签名（对象存储/本地均支持，可配置有效期）、存储支持多实例配置（本地/腾讯云 COS/阿里云 OSS/华为 OBS/AWS S3/又拍云/七牛）、后台仪表盘重做为运营中心（流量统计/系统状态/趋势图表），并上线像素风格品牌视觉体系。

### 破坏性变更（Breaking Changes）

- **图片链接不再永久公开**：所有图片 URL 默认带短时签名（有效期默认 300 秒，可在存储管理按实例调整）。对外固定引用需配置 CDN 加速域名（存储管理 → 实例配置 CDN URL）才会生成永久直链。
- **存储配置迁移**：单实例 `storage_*` 设置迁移至 `storage_profiles` 多实例模型（运行时自动迁移，老配置无缝升级，无需手动操作）。
- **重定向接口语义统一**：`/api/v1/random?redirect=1` 等返回 302 时使用签名 URL。

### ✨ 新功能（Features）

- **短时临时签名链接**：COS/OSS/AWS S3/OBS 云商原生预签名（不经服务器代理）+ 本地 `GET /files` 签名下载端点（HMAC-SHA256 + 过期 + 路径穿越防护）
- **存储多实例**：每个实例独立配置（驱动/服务商/凭据/路径/CDN/签名有效期），后台「存储管理」独立板块管理
- **流量统计**：API 调用量 + 网站访问量按日统计（自动埋点，仪表盘展示今日/近 7 天/累计 + 趋势图）
- **仪表盘重做**：最近上传、分类分布、存储用量、7 天上传趋势、最近操作日志、系统状态（CPU/PHP 内存/磁盘）
- **品牌视觉**：像素 Logo/Favicon/Hero 横幅/OG 分享图，前台后台安装页全站落地

### ⬆️ 功能增强（Enhancements）

- 图片管理：分页每页数量选择（10/20/50/100）、跨页全选（「全选」+「全选本页」）
- 后台「Dashboard」→「仪表盘」，全站语言统一
- 后台侧边栏/登录页/安装向导品牌化

### 🐛 Bug 修复（Bug Fixes）

- 批量上传超限误报 419 → 明确 413 + 前端预检
- 图片管理「全选」接口 500（Model 数组访问）
- 上传进度条文字裁剪/遮挡（重做为文字行 + 胶囊渐变轨道）
- 仪表盘 500：宝塔 disable_functions 禁用 shell_exec（改纯 PHP 原生）
- 全选接口/视图防御性兜底（混搭部署不 500）

### 🚀 性能（Performance）

- 品牌资源 WebP 化 + LCP 预加载 + `fetchpriority=high`
- 图片显式 `width/height` 消除 CLS；深色主题对比度达 WCAG AA
- `<main>`、`meta description`、表单 label、标题层级等可访问性修复

### 升级指南（Upgrade Guide）

1. 备份数据库（可选但建议），下载 zip 覆盖部署（项目根 doc-root）。
2. 重启 PHP-FPM：运行时迁移自动完成存储配置迁移 + 创建统计表（`api_stats`/`visit_stats`），**无需手动 SQL**。
3. 访问首页一次 + 调用任意 API 端点触发统计埋点。
4. 运行 doctor.php 验证：`Signed links`、存储实例、迁移状态应全绿，验证后删除。
5. 检查「存储管理」各实例：签名有效期（默认 300 秒）与 CDN 域名是否符合预期。
6. 硬刷新（Ctrl+Shift+R）查看新品牌与仪表盘。
